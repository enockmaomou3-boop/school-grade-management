# 📚 Gestion des Notes Scolaires

Plateforme moderne de gestion des notes scolaires pour directeurs d'école.

## 🎯 Fonctionnalités

- ✅ **Gestion des élèves** - Enregistrement complet (nom, classe, matricule, tuteur)
- ✅ **Saisie des notes** - Par classe, matière et trimestre
- ✅ **Calcul automatique** - Moyennes pondérées par coefficient
- ✅ **Bulletins** - Génération et impression des bulletins de notes
- ✅ **Dashboard** - Vue d'ensemble par classe
- ✅ **Stockage local** - Données sauvegardées dans le navigateur

## 🚀 Installation rapide

```bash
# Cloner le repo
git clone https://github.com/enockmaomou3-boop/school-grade-management.git
cd school-grade-management

# Installer les dépendances
npm install

# Lancer le serveur de développement
npm run dev

# Construire pour la production
npm run build
```
